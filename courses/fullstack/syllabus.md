# Recorrido

La primera unidad profundiza autorización mediante ownership y roles. Luego conecta esas reglas con consultas, validación, errores y consistencia de datos.

## Recorrido completo

Explicar y justificar un diseño web completo, desde la interacción hasta los datos y la operación, mediante contratos, diagramas, escenarios y verificaciones, sin stack obligatorio.

Las lecciones 1–14 forman el bloque inicial ya publicado. El curso completo contiene 130 pasos; los siguientes se distribuyen así:

| Lecciones | Módulo |
|---|---|
| 15–20 | Mapa completo de una aplicación |
| 21–27 | Lenguaje y razonamiento de programas |
| 28–34 | Asincronía y tipos |
| 35–39 | Entorno y control de versiones |
| 40–45 | HTML y accesibilidad |
| 46–51 | CSS y diseño adaptable |
| 52–58 | Navegador y HTTP |
| 59–65 | Backend y contratos de API |
| 66–73 | Datos y SQL |
| 74–79 | Persistencia y evolución |
| 80–86 | Identidad y seguridad aplicada |
| 87–93 | Interfaz con componentes |
| 94–99 | Integración de cliente y servidor |
| 100–105 | Pruebas y depuración |
| 106–111 | Rendimiento y observabilidad |
| 112–118 | Integraciones y arquitectura |
| 119–125 | Entrega y mantenimiento |
| 126–130 | Caso integrador y revisión |

Cada paso combina explicación, ejemplo y práctica verificable. Los repasos conectan conceptos anteriores; publicar no acredita que el alumno los haya dominado.
