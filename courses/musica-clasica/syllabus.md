# Recorrido

El curso no presupone teoría musical. Cada término nace de algo que primero puede escucharse y describirse con palabras comunes.

## Recorrido completo

Escuchar obras completas, reconocer sus recursos y formas, situarlas históricamente y comparar interpretaciones con argumentos auditivos sin requerir lectura musical.

Las lecciones 1–14 forman el bloque inicial ya publicado. El curso completo contiene 95 pasos; los siguientes se distribuyen así:

| Lecciones | Módulo |
|---|---|
| 15–19 | Afinar las herramientas de escucha |
| 20–25 | Instrumentos y conjuntos |
| 26–31 | De la monodia a la polifonía |
| 32–38 | Barroco instrumental |
| 39–43 | Voz, palabra y escena barroca |
| 44–50 | Clasicismo y formas amplias |
| 51–55 | Beethoven y las transformaciones del lenguaje |
| 56–61 | Romanticismo: piano y canción |
| 62–67 | Romanticismo: cámara y orquesta |
| 68–73 | Ópera y teatro musical |
| 74–78 | Diversidad del siglo XIX y cambio de siglo |
| 79–86 | Siglo XX y música reciente |
| 87–91 | Interpretación y grabación |
| 92–95 | Escuchar obras completas con autonomía |

Cada paso combina explicación, ejemplo y práctica verificable. Los repasos conectan conceptos anteriores; publicar no acredita que el alumno los haya dominado.
